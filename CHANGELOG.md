# Version history

## 1.2.0 — 11 October 2026

- Added authenticated same-machine browser access at http://127.0.0.1:17373, sharing desktop SQLite data and real printer jobs.
- Removed the browser demo fallback and scheduled cleanup of retired demo storage.
- Updated touch layouts, menu management, order history, sales reports, settings and bill/KOT previews.
- Added date/status filters, reporting exports, availability controls, product choices and receipt-preview zoom.
- Browser and desktop sessions are separate; backup and restore remain desktop-only.
- Existing shop data, staff accounts and order history are retained.

## 1.1.1 — 11 October 2026

- Simplified the billing screen to focus on adding items, adjusting quantity, choosing payment and saving/printing the bill.
- Moved sales summaries out of the cashier billing screen and collapsed optional discounts, tax details, cash tender and kitchen notes until requested.
- Kept the current Chef Warriors logo, dark interface and yellow accents.

## 1.1.0 — 11 October 2026

- Replaced the sample menu with 76 entries in 17 categories from the client's four menu cards.
- Added portions, bucket contents, combo contents and required choices; separate configurations can coexist in one cart.
- Added The Chef Warriors logo, yellow/red/black styling, tagline, address and phone number.
- Included selected combo details in customer bills and price-free KOTs.
- Added one-time desktop catalogue migration with a consistent safety backup; retained accounts, historical sales, invoice numbering and configured printers/tax.
- Cleared old browser demonstration records once while retaining a localStorage copy.
- Included the checkout visibility fix for short desktop windows.

Install this update over the existing app using the same Windows account. Close the running app first. No uninstall or new admin account is required. The installer remains unsigned; physical printer acceptance is still required.

Initial browser demonstration and offline desktop POS, with sample menu data.
